# ski-user-web

> Ski Coach 用户端Web应用 - 基于 Vue 3 + Vite + Element Plus 实现

## 状态

🚧 **待开发(P3阶段)** - 此目录目前为空,P2完成后开始填充。

## 计划技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Element Plus
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **HTTP客户端**: Axios
- **样式**: SCSS
- **包管理**: npm

## 核心页面(待P3完成后实现)

- 注册/登录
- 视频上传
- 我的视频列表
- 单次报告查看
- 选择两个视频生成对比报告
- 对比报告查看
- 个人资料

## 启动方式(待P3完成后填充)

```bash
npm install
npm run dev
```
